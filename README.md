# Social Media Analysis – SQL Project

## Project Overview

This project analyzes an Instagram-style social media database using SQL to understand user behavior, engagement patterns, content performance, and social connections.

The main objective is to transform raw relational data into meaningful insights that can support user engagement, retention, marketing strategies, and creator identification.

## Problem Statement

Social media platforms generate large amounts of user interaction data every day. Raw data alone does not clearly show which users are active, which content performs well, or which users may be becoming inactive.

This project uses SQL to analyze posts, likes, comments, followers, followings, and hashtags to identify important patterns and insights.

## Dataset

The database contains the following tables:

- Users
- Photos
- Comments
- Likes
- Follows
- Tags
- Photo Tags

## Objectives

- Analyze user activity and engagement.
- Identify active and inactive users.
- Analyze likes and comments on posts.
- Identify high-engagement content creators.
- Analyze followers and followings.
- Analyze hashtag usage.
- Identify mutual connections.
- Segment users based on activity levels.
- Generate business insights from social media data.

## Data Cleaning

The dataset was checked for duplicate records and missing or NULL values before analysis. Primary keys, composite keys, and NOT NULL constraints were also considered to maintain data integrity.

## SQL Techniques Used

- SELECT, WHERE, GROUP BY, HAVING, ORDER BY
- JOINs and LEFT JOINs
- Aggregate Functions
- Subqueries
- Common Table Expressions (CTEs)
- Self JOIN
- Window Functions
- DENSE_RANK()
- COALESCE()
- CASE Statements

## Key Analysis

The project includes user activity analysis, engagement analysis, hashtag performance, follower and following analysis, mutual connection analysis, and user segmentation.

Engagement was analyzed using likes, comments, and posting activity to understand content performance and identify highly engaged users.

Hashtag usage was analyzed to understand which topics receive greater interaction. User activity was also used to classify users into different engagement groups such as Content Creators, Active Engagers, and Inactive Users.

## Business Insights

The analysis helps identify active users, high-engagement creators, popular hashtags, inactive users, and important social connections. These insights can support targeted engagement campaigns, creator partnerships, marketing strategies, and user retention activities.

## Conclusion

This project demonstrates how SQL can transform raw social media data into structured insights and support data-driven business decision-making.
